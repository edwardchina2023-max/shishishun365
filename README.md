# 事事顺酒品牌官网

“喝事事顺酒 事事顺”品牌展示网站，延续原站的中国红、古金与暖白视觉体系，重点呈现事事顺365、事事顺516、事事顺·中国红、事事顺·家顺四款主打产品。

## 本地预览

在项目根目录运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。

## 发布

项目为纯静态网站，可直接由 GitHub Pages 从 `main` 分支根目录发布。

## 主要文件

- `index.html`：网站结构、品牌文案与 SEO 信息
- `assets/css/style.css`：桌面端与移动端视觉系统
- `assets/js/main.js`：年龄确认、导航、滚动显现与产品切换
- `assets/images/brand/`：品牌标准字与组合标
- `assets/images/products/`：四款主打产品实拍素材
